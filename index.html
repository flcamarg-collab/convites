Como usar no dia

  1. Cada pessoa da equipe de acolhida abre o link deste aplicativo no celular e entra com o PIN da acolhida.
  2. Toque em Abrir câmera (ou Tirar foto, se a câmera ao vivo não abrir) e aponte para o QR code no celular do convidado.
  3. Verde = entrada liberada. Laranja = convite já usado. Vermelho = convite inválido ou cancelado.
  4. Cada QR code vale para uma pessoa e só entra uma vez – mesmo se lido em celulares diferentes.
